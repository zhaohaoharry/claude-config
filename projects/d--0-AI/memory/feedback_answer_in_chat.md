Answer in the chatbox by default. When the user asks to see a proposed paragraph or rewrite, print it in the reply, not in a compiled PDF or a new file.

**Why:** on 2026-11-11 I compiled a three-page PDF to show a proposed shortening of a manuscript subsection; the user said "normally you should just answer in the chatbox unless I ask."

**How to apply:** proposed prose goes in the reply as plain text (write a lone symbol in plain characters, such as τ_is). Build a file only on request, or when the answer is mostly equations, where [[math-compilation]] still applies. Related: [[feedback-open-pdf-in-preview]].
