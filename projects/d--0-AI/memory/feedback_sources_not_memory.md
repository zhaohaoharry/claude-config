Anything written into a manuscript (numbers, parameter values, characterizations of papers, institutional facts) must be taken from an actual document or dataset that was retrieved and read in the session, with the exact location recorded (table/page/file). Values recalled from memory may be used only as search leads, never as content.

**Why:** Stated by the user 2026-10-19 as "the rule for all future studies" after the Carbon Batteries model shipped with parameters tagged VERIFY (IPCC half-lives, carbon factors) that came from memory.

**How to apply:** Before a number enters a manuscript or a parameter file used for manuscript results, fetch the source (Zotero first per [[feedback_zotero_first]], then the official document/data portal), record citation + table/page beside the value, and mark anything not yet retrieved as an open TODO rather than writing it. Related: [[feedback_no_cross_document_mentions]].
