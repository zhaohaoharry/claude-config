When asked to "update the introduction and conclusion to reflect the results", change the numbers and wording of the descriptions already there and discuss gaps in chat; do not insert new sentences, clauses, citations, or implications, even for findings newly settled in the main text.

**Why:** On ETFP (2026-10-19) the user rejected every added sentence (Shapiro–Walker comparison, desulfurization validation, technology-redirection sentence, explanation of the small induced effect, closing implication): "the general idea is to update previous descriptions and discuss, not to add new contents."

**How to apply:** Edit in place only where an existing statement is wrong or stale. List findings the intro/conclusion do not mention as suggestions in the reply, and add them only if the user asks. Related: [[feedback_edit_only_what_needs_change]], [[feedback_minimal_track_changes]].
