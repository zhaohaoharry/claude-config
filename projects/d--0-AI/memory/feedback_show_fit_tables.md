When reporting fit, moments, or any comparison across models or specifications, show a table or figure next to the text. Do not describe it in prose alone.

**Why:** user, 2026-11-07: "when you talking about the fitting. can you show a table besides the text. I always want to see tables/figures for illustration rather than just reading the text."

**How to apply:** in chat, use a data-versus-model table with the numbers read from the result files. For anything that plots better, build a compiled figure PDF, open it, and sync it to AI_share. Related: [[feedback_always_show_es_figures]].
