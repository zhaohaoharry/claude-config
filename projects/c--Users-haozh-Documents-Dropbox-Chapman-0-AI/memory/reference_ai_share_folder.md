`D:\AI_share` is a sync folder the user can open from their phone (set up 2026-10-07). When the user asks to send/share/put PDF results "to the share folder" or "to my phone", copy the compiled PDF(s) there (copy, never move; keep the project copy as the source of truth). Use a descriptive filename so the file is identifiable on the phone.
