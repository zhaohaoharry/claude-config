Inside any manuscript, never mention the project's other internal documents
(the working paper, the memo, "the companion framework", other model notes)
unless the user explicitly asks for such a cross-reference.

**Why:** The user (2026-09-01, Carbon Pricing Policy structural_model.tex)
struck "the representation also used in the companion framework of the
working paper" with "never mention the other notes unless I asked". Each
document must stand alone; internal drafts are not citable objects and the
set of documents changes as the project evolves.

**How to apply:** Cite published literature only. If alignment with a
coauthor's draft motivates a choice, keep that in the chat reply, HANDOFF,
or session log — not in the manuscript. Related:
[[feedback-no-process-narration]].
