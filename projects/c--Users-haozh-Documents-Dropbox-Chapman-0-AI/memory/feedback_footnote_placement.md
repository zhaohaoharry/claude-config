Place `\footnote{}` at the end of a sentence (after the period) or, if it must attach to part of a sentence, after the comma that closes that part. Never attach it to a bare word mid-clause (e.g. `Chinese provinces\footnote{...} are led by`).

**Why:** The user stated this as a standing rule on 2026-09-07 while reviewing the IER manuscript; a marker hanging off a noun mid-sentence reads as a typographic interruption.

**How to apply:** When adding a footnote, move the marker to the nearest following punctuation and restructure the sentence if needed so the note still attaches to the right idea. When editing a manuscript, scan for `\footnote{` not preceded by `.` `,` `;` `:` `)` or a closing quote and fix each. Related: [[feedback-edit-only-what-needs-change]].
