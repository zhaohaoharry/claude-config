# Diagnostics for a high-ceiling economics introduction

## Six general-interest tests

### 1. Setting-removal test

Delete the country, policy, institution, period, and dataset from the pitch. If no consequential economic question remains, the paper is setting-led. Reframe around the general problem, then restore the setting as leverage rather than motivation.

### 2. Travel test

Ask whether the main contribution is a fact that lives only in the sample or an explanation that predicts behavior elsewhere. A portable mechanism raises the ceiling only when the evidence distinguishes it from plausible alternatives.

### 3. One-sentence transmission test

Ask a reader outside the subfield to complete this sentence: "The paper shows that..." If the answer requires a list, the paper lacks a hierarchy. Choose the result that governs the interpretation of the others.

### 4. Escalation test

Label each later analysis by its role: identify, discriminate, quantify, bound, establish scope, or validate. Analyses labeled merely "another outcome" or "another robustness check" should not occupy prime introduction space.

### 5. Literature-revision test

Complete one of these claims only when accurate:

- The estimate changes a canonical calculation because...
- The evidence resolves an apparent contradiction because...
- The mechanism connects two literatures that treated the same force separately because...
- The result changes the incidence or policy conclusion because...

If none fits, state the narrower knowledge gain precisely. Do not manufacture a literature revolution.

### 6. Ambition-and-test test

Write the boldest interpretation the current evidence can responsibly support. Then write the stronger claim the author would like to make and the additional test needed to support it. Keep the first in the paper. Use the second to guide new analysis.

## Reader-reaction map

Drafting should manage beliefs, not emotions through hype. For the first page, write a private two-column map:

| Reader inference | Evidence or sentence that earns the better inference |
|---|---|
| "This is obvious." | State the unresolved tradeoff, ambiguous sign, or missing magnitude. |
| "This is one institutional anecdote." | Pose the general problem first and show why the institution isolates it. |
| "The author is overselling." | Match the breadth of the claim to the variation and tests. |
| "The design cannot answer that." | Explain the identifying comparison and dominant threat directly. |
| "This is a results inventory." | Organize results as answer, mechanism, scope, and implication. |
| "The literature already did this." | State what becomes known, not merely what object is newly studied. |

## Objection triage

- **Fatal:** undermines identification, measurement, model discipline, or the central interpretation. Fix the research design or narrow the claim.
- **Claim-limiting:** preserves the estimate but reduces its generality or mechanism content. State the correct boundary and, where possible, add a discriminating test.
- **Local:** concerns implementation detail or a secondary specification. Handle in the body unless one short sentence resolves the reader's dominant first-page concern.

Do not respond to each objection by adding prose. Extra text is warranted only when it changes the reader's assessment of the question, credibility, magnitude, or interpretation.

## Paragraph pressure test

For every paragraph, write its intended belief change in the margin. If two paragraphs make the same change, combine them. If a paragraph makes no change, cut it. If a paragraph tries to make three changes, split or reprioritize it.

For every sentence, identify its function: premise, gap, question, design logic, result, interpretation, mechanism, scope, contribution, or orientation. Delete sentences whose only function is emphasis, anticipation, enumeration, or self-description.
